Example docs site

This page stands in for a customer's documentation site. It has its own fonts and styles; the chat widget in the corner is isolated in a Shadow DOM so neither affects the other.

Embed code used on this page:

<script src="/widget.js" data-title="Ask the uv docs" data-color="#7c3aed" async></script>
